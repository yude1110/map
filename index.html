    建議行程

    地點來自 Google Places，交通時間來自 Google Routes：大眾運輸依指定日期時間的班表，開車與機車含預測路況。開車另加 10 分鐘停車、計程車加 5 分鐘等車。

    在地圖上點一個地點或位置

    先設定 Google Maps API 金鑰

    地點搜尋、班表和路況都來自 Google，需要你自己的金鑰。金鑰只存在這台電腦的瀏覽器裡。

    1. 到 Google Cloud Console ↗ 建立專案並設定帳單。
    2. 啟用三個 API：Maps JavaScript API、Places API (New)、Routes API。
    3. 建立 API 金鑰。應用程式限制選「網站」，加入 http://localhost:8080/*；API 限制勾選上面三個。
    4. 把金鑰貼在下面。
